# Modern Calculator — CodSoft Level 1 Task 3

A modern, responsive calculator built with HTML, CSS, and JavaScript.

## Project Structure

```
calculator/
│
├── index.html        ← Main HTML file (open this in browser)
├── css/
│   └── style.css     ← All styling (layout, colors, animations)
├── js/
│   └── script.js     ← All calculator logic
└── README.md
```

## How to Run

1. Download / clone the folder
2. Open `index.html` in any browser — no server needed

## Features

- All 4 operations: addition, subtraction, multiplication, division
- History row showing the current expression
- Active operator highlight
- AC (clear), +/− (toggle sign), % (percentage)
- Chained calculations (e.g. 5 + 3 × 2)
- Division by zero error handling
- Long number font shrinking
- Keyboard support:
  - `0–9` → digits
  - `+ - * /` → operators
  - `Enter` or `=` → equals
  - `Backspace` → delete last digit
  - `Escape` → clear all

## Technologies

- HTML5
- CSS3 (Grid, custom properties, transitions)
- Vanilla JavaScript (no libraries)
